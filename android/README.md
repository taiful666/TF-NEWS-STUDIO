# TF News Studio — Android app

এই ফোল্ডারে ফোনের অ্যাপের কোড আছে। ডেস্কটপের `index.html` আলাদা, সেটা বদলায় না।

- মোবাইল অ্যাপের পর্দা: `mobile/index.html`
- প্রতিবার `mobile/` বা `android/` ফোল্ডারে পরিবর্তন হলে GitHub নিজে থেকে নতুন APK বানায়।
- সর্বশেষ APK: https://github.com/taiful666/TF-NEWS-STUDIO/releases/latest/download/TF-News-Studio.apk

`app/tf-test.keystore` শুধু পরীক্ষার জন্য। Play Store-এ দেওয়ার আগে আলাদা গোপন সাইনিং কী বানাতে হবে।
